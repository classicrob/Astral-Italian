## Manual review at the recorded base

No gameplay math/physics/collision/RNG helper is confirmed silently empty by this structural audit. The candidate counts below intentionally retain benign platform differences. This review is static; no runtime equivalence or successful native link is claimed. The following notes are manually reviewed additions to the generated inventory and should be rechecked after regeneration.

- **Vector constructor (b/d):** `TVec3<s16>::TVec3` only loses `x = x`, a matching-only self-assignment whose adjacent comment explains why the Wii constructor is emitted. Neither branch initializes the vector components. This is not evidence of a lost arithmetic operation.
- **GQR setup (a/d/e):** `OSInitFastCast` and `J3DSys::drawInit` write PPC quantizer registers. Host casts have no such registers; `OSInitFastCast` is already explicitly allowed by [the imported check](../../native/tests/asm_only_bodies_tests.py#L40). These omissions are expected platform setup differences.
- **Pointer assertions (a):** `CharWriter::SetupGX` drops Wii address-range assertions. Those ranges do not describe native pointers; its GX setup remains outside the guard.
- **DSP context (b):** `__DSPHandler` omits the Wii exception-context cleanup. [Its native entry branch](../../src/JSystem/JAudio2/osdsp_task.cpp#L31) explains that the host DSP interrupt thread has no exception context to switch.
- **Panic stack (b):** `VPanic` already calls native `ShowStack_()` at [line 87](../../src/nw4r/db/db_assert.cpp#L87), before the later excluded Wii `ShowStack_(stackPointer)` call. This is a replacement elsewhere in the function, not a missing native diagnostic.
- **Audio archive constructor (d, configuration-dependent):** [AudSystemWrapper.cpp](../../src/Game/System/AudSystemWrapper.cpp#L1) defines `AUD_ARCHIVE_SET_MANUAL_RESET` and explicitly calls `mArchives.reset()` in the wrapper constructor at line 34 and teardown at line 275. The standalone header scan cannot see that inclusion context. No missing reset is established here.
- **SDK assembly (e):** Most entries are hardware implementations outside the native build's selected source lists. The five top-ranked GX transform writers/copies are in the RVL SDK backend; [native GX](../../native/gx/CMakeLists.txt#L38) selects Aurora's transform implementation. [Movie targets](../../native/movie/CMakeLists.txt#L26) select Aurora's THP decoder. [Platform documentation](../../native/platform/STATUS.md#L731) lists the replaced PPC/OS implementations. Do not port these assembly sites solely because they appear in this inventory.
- **Excluded math definitions (e):** 17 sites in `src/RVL_SDK/mtx/` are already excluded by native guards. [native/src/mtx.cpp](../../native/src/mtx.cpp#L27) provides portable vector/matrix/quaternion functions alongside the SDK C portions in [petari_core](../../CMakeLists.txt#L40). The internal `__PSMTXRotAxisRadInternal` is Wii implementation detail. The scanner does not prove every public symbol's provider, build membership, or numerical behavior; these rows remain visible for that separate check.

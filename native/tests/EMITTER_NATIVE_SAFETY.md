# Native emitter conversion and follow-byte regression tests

Run `python3 native/tests/emitter_native_safety_tests.py` on M1. This compiles both complete production emitter translation units with ASan, UBSan and float-cast-overflow checks, using the owning game headers and canonical `JMath::truncToS16`. The callback executable links the real JPA callback destructor, matrix/trig providers and AutoEffectInfo constructor. Its only test double is an inert MultiEmitter constructor that bypasses resource loading. No emitter spawning, renderer or gameplay behavior is claimed.

The original DOL multiplies the binary32 degree by `0x43360b61` (182.04444885253906), uses `fctiwz`, and sign-extends the low 16 bits. Native conversion preserves that integer result through the canonical signed-word conversion, including NaN and overflow. It does not emulate FPSCR flags, traps, paired lanes or NaN payload propagation.

`FlagSRT` uses three bytes natively because the Wii loads each byte and compares it with zero. Any defined nonzero byte is true; unnamed bits are neither discarded nor forced to zero. The callback's own flags and AutoEffectInfo flags remain unsigned 16-bit storage. Tests cover every callback and AutoEffectInfo bit combination, all 256 incoming byte values, host pointer gates, phase boundaries, nonfinite values and sampled float bit patterns. Mutants restoring the original direct float-to-s16 conversion or bool storage must fail the sanitizer checks.

There is a separate unresolved path: `followSRT` declares an uninitialized FlagSRT, and `isFollowSRT` can retain an incoming byte when AutoEffectInfo is null and a corresponding host pointer is present. Constructors permit this state. The native byte representation removes invalid-bool loads for defined raw bytes; it does not establish a value for indeterminate caller storage. No zero initialization was added. Tests supply defined input bytes and exercise the full caller only with null hosts, where every byte is overwritten before use. This is a partial repair, not closure of all executions represented by the historical U021/U022 diagnostics.

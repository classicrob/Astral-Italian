`v2.txt` and `stale.txt` are synthetic reports; the latter deliberately disagrees
with its Binary Images UUID. `demo.ips` retains only the crash-relevant JSON from
a real macOS 15.1 report generated by `petari_crash_demo` with
`PETARI_TEST_CRASH=segv-write` and `--no-handler` on 2026-10-23. Its executable
path is replaced with `/synthetic/petari_crash_demo`; process/session identifiers
and unrelated OS metadata are omitted. All code and data are synthetic; no disc
content is used. The actual UUID is intentionally retained to test real IPS
parsing independently of whether that demo's dSYM is still available.

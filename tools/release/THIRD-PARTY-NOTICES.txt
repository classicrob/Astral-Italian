Astral Italian: third-party software
====================================

Astral Italian's own source code is released under CC0 1.0 (see LICENSE.txt). It contains no Nintendo game
data. The app is linked with, or ships alongside, the following open-source software, each used under its own
license (full texts: the linked project pages and, for the libraries in Contents/Frameworks, their upstream
distributions).

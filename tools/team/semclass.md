# semclass (reviewed code V3, fail closed)

`semclass.py` classifies every paired objdiff function at >=90% without the old REALDIFF register/label prefilter. Its independent `semdata.py` audit visits ALL functions, including code100, code<90, functions without instruction rows and source-only functions. Source-only results are separate advisories: no original target identity is invented. A unit/tool/data failure is an explicit unresolved result.

```
python3 tools/team/semclass.py --root . --prefix Game/Player/ \
  --semdata tools/team/semdata.py --semdomain tools/team/semdomain.py \
  --out /tmp/semclass-player.json
python3 -m unittest discover -s tools/team -p 'test_sem*.py'
```

No compilation, source/metadata/proof edits, or dependency downloads occur. Full objdiff JSON pairs are saved beside the report. The original DOL, metadata, actual objects, helpers and encountered provider/header inputs are hashed and rechecked at the END of the complete run. Any instability invalidates conclusions. `gate_ready` is deliberately false: repository integration does not itself certify a new checkout or satisfy the finish-line gate. See the pinned review below.

## Proof boundary

An exact-identity certificate compares complete machine words modulo validated relocation fields, identical resolved code referents and branch coordinates, with data referents delegated to the separate mandatory audit, and binds every target word/reference to the original DOL. Unchanged helpers, unknown opcodes or mixed-width stack operations need no semantic lowering. This is a conditional code certificate: differing data addresses/values remain independent obligations and prevent whole-function ABI when unproved.

Otherwise a bounded acyclic CFG/value/effect DAG checks entry values, return/live register boundaries, copy aliases and supported integer/FP operations. Branch polarity inversion is accepted only with the corresponding successor swap; compares retain signedness and immediates. Calls remain opaque barriers. Unspecified volatile call outputs remain side-specific; multiple opaque calls may therefore be conservatively unresolved. Every load has a distinct ordered occurrence. Loads never cross calls or other loads. Same-SSA-base, disjoint-range store scheduling is permitted only in an explicitly ordinary domain. Missing domain evidence defaults to strict total memory order.

Absolute-immediate/device origins survive arithmetic, copies, PHIs, update-form effective addresses, and alias-conservative store/load spills. A tainted stored value may taint any later possibly overlapping load; only static disjoint intervals of the same SSA root exclude that flow. Volatile global symbols match canonical names or MWCC name__scope names; loads from strict pointer globals taint derived bases. Domain input and encountered device/symbol domains are reported. The frozen review uses root domain V4, including its SHA-pinned declarations and tests. A supplied volatile-member range currently forces conservative whole-function strictness rather than silently granting ordinary-domain scheduling; range-sensitive root+delta coverage is not claimed.

Fixed straight-line private frames support typed equal-size slot bijections and validated entry-nonvolatile/LR saves with terminal restores. Original-DOL-bound GPR helpers can be expanded in this restricted context. Their reaching r11 frame-end setup may precede independent straight-line instructions; intervening r11 reads/clobbers, branches, calls or frame changes fail closed. The unique entry mflr and its linkage store must precede every helper, and the linkage reload/mtlr must follow every helper, so erasing a helper never erases an observable LR definition. Tail helper transfers remain unsupported. All explicit r1 uses except admitted direct memory bases and frame allocation/release are escapes. Stack addresses passed to calls require unavailable full out-parameter extent proofs when a remapping is needed, and remain unknown. Read-before-write remapped slots are semantic (`uninitialized-stack-read`); incoming caller-stack slots cannot be arbitrarily remapped. A shrinking frame carries `frame-shrunk`.

Permitted FP commutation is explicit: fadd/fadds, fmul/fmuls, and fmadd/fmadds multiplicands. Grouping, fused/separate operations, precision, conversions and ordered FP event effects remain distinct. This port policy is not a claim of exact Gekko operand-order equivalence.

## Referents and output

Actual local locations resolve from the owning TU section and object offset; duplicate/unknown mappings fail closed. Only a direct typed load from an appropriate readonly section may use bit-identical literal bytes. Forming/passing addresses retains object identity; equal strings, tables, mutable initial values or synthesized zero-BSS do not establish identity. `semdata` checks complete extents, consumed spans, actual pointer identities and original-DOL backing. Unknown indexing/pointees/trace coverage remains semantic, independently of observed byte mismatches.

`classification` is ABI only after code and data obligations close. `code_classification` separates provisional code proof/unknown from data findings; SEMANTIC includes unsupported cases and is not a bug count. `objdiff_differing_rows` preserves ALL actual differing rows with both function-relative offsets. Normalized `differences`, `findings`, subclasses, ABI tags and unknown-opcode coverage explain the result. Data-only findings have referents/data offsets and do not invent differing instructions. Raw counts are retained. Optional trusted `--code-proofs FILE` inputs apply scoped unit+symbol code exemptions only AFTER classification. Bare names require a complete unique-unit census of every configured target ELF; ambiguity/missing census fails closed. All proof files and census inputs are pinned. Data findings/unknowns remain open regardless of a code exemption; this version accepts zero data waivers. JSON includes raw and code-filtered counts.

## Tests and limitations

`fixtures/semclass-known-bugs.json` supplies seven bounded, bound-reference operand-role negative controls plus Jet's actual 48B historical payload and four bad slots. `test_semdata` synthesizes portable ELF/DOL inputs to exercise the object-backed Jet regression despite identical text; a correct-data control only removes byte mismatches and leaves indexing unknown. These are regression witnesses, not whole-function equivalence proofs. The full historical eight-object archive is an additional optional integration oracle (`--fixtures FILE`, `SEMCLASS_FIXTURES=DIR`). Permanent controls do not require that archive.

The frozen semdecode dependency adds exact extrwi[.] to nonwrapping rlwinm[.] and subi to signed16 addi lowering, dynamic lwzx addresses with architectural RA=0 versus real RB=r0, and bctrl with CTR plus opaque call ABI inputs/clobbers. Indexed EAs retain actual SSA operand values and address taint; dynamic aliases do not receive a disjointness exemption. Indirect calls preserve all ordinary call barriers and unspecified volatile-output havoc. Unsupported opcodes, cyclic/unsupported indirect control flow, complex/out-parameter frames, opaque-call output reuse and unresolved referents remain SEMANTIC. Full raw counts, unresolved units, provider pins and source-only advisories must accompany any gate proposal. No signoff or zero-semantic claim is made by this experimental package.
